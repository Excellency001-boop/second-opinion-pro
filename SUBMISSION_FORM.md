## The problem (if there is a problem field)
Everyone can see their portfolio risk. Almost nobody fixes it in time. Human portfolio managers are slow and expensive, and the new wave of AI portfolio tools only describe the problem, they do not settle anything. And an autonomous agent that moves real money is frightening unless a human keeps a hand on the wheel. There is no tool today that can diagnose the risk, delegate the fix to specialists, pay them, execute on-chain, and keep the person in control.

## What it does (if there is a solution / description field)
1. Grades your on-chain and tokenized-asset portfolio across seven health checks, from A+ to D: leverage, biggest position, move-together risk, cash buffer, diversification, drop-from-peak, and leverage cost. Deterministic and explainable.
2. Drafts a plan and maps each fix to a specialist agent.
3. With your approval, a coordinator agent hires each specialist over A2A, pays it per task via x402, and has it execute on X Layer. The book rebalances and the grade climbs, live, one step at a time. In the demo an at-risk book graded D becomes A- after risky positions are rotated into a tokenized blue-chip plus a cash buffer.
4. Keeps you in the seat: a fee cap, a trade-size cap, an approval toggle, a full audit trail with on-chain references, and a red kill switch that stops everything instantly.

## How it uses the OKX stack (if there is a technical field)
- X Layer: tokenized stocks are treated as first-class building blocks and used as the destination for de-risking. The app is connected live to X Layer (the header shows the current block).
- OKX AI: a real agent economy. A coordinator with its own on-chain identity discovers specialists (each an ERC-8004 identity on X Layer), hires them over A2A, and pays them per task with x402. Real discovery, coordination, and monetisation between agents.
- Hosted and always on: Next.js on Vercel, serverless functions for the agent brain, a serverless database for state, and a heartbeat that advances work unattended. No machine of the user's has to stay on.

## What is real, stated honestly
The live X Layer connection, the deterministic grading engine, the on-chain agent identities, the hosted always-on architecture, and the full human-oversight controls are all real today. Agent hiring, payment, and execution run in a faithful simulation that is clearly labelled in the audit trail, and flip to real X Layer transactions when the agent wallet is funded (a one-line switch). We do not present simulation as reality anywhere.

## What is built
A working, deployed product, not a mockup. Open the live URL, pick the at-risk book, press Get a second opinion, approve the plan, and watch the grade climb while you hold the kill switch. Includes a tested grading engine and a clean, plain-language interface designed so a non-expert understands it in seconds.
